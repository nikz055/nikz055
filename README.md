## About

I'm an M.Tech AI student with an electronics and computer engineering background. Most of my work starts with a
measurement: where the time goes in a model, which signal actually drives a prediction, or what a system does when two
requests arrive at once. I then build the smallest change that fixes what the measurement shows, and check that it
did.

I work across predictive modelling on engineering data, explainable ML, vision-language models on constrained
hardware, and LLM applications where deterministic code keeps the model in check. Before the M.Tech I worked as a
full-stack developer on battery-performance data pipelines and dashboards.

## Currently

- **Token reduction in vision encoders**: merging, pruning and how to recover the quality they cost.
- **LLM agents with hard limits**: language models that propose actions, with code that verifies them before anything
  happens.
- **Calibrated prediction**: models that can say "not sure yet" instead of forcing a yes or no.
